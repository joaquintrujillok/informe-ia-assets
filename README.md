# informe-ia-assets

Imágenes del informe de IA de Adoops Digital.

Se sirven directo por `raw.githubusercontent.com` desde el correo. Cada edición
tiene su carpeta bajo `img/YYYY-MM-DD/`.

Solo se publica aquí material que ya era público: benchmarks publicados,
anuncios oficiales y gráficos de medios.
